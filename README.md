# IMDb Sentiment Analysis — End-to-End NLP Classification

An end-to-end Natural Language Processing (NLP) project that classifies IMDb movie reviews as **positive** or **negative** sentiment.

The project covers data cleaning, exploratory data analysis, TF-IDF feature extraction, model comparison, evaluation, error analysis, a command-line interface (CLI), and a FastAPI prediction API.

---

## Project Overview

The goal of this project is to build a complete text classification pipeline for movie-review sentiment analysis.
